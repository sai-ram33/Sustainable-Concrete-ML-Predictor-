HOW TO USE – SUSTAINABLE CONCRETE ML PREDICTOR
  1. ENTER MIX PROPORTIONS
    • Cement: 280–450 kg/m³
    • Water: 135–205 kg/m³
    • Fine Aggregate: 600–849 kg/m³
    • Coarse Aggregate: 900–1196 kg/m³
    • Water/Binder Ratio: 0.12–0.52
  2. ENTER SUSTAINABLE MATERIALS
    • Fly Ash: 0–30%
    • GGBS: 0–45%
    • Silica Fume: 0–12%
    • RHA: 0–12%

    Enter 0% if a material is not used.

  3. SELECT PARAMETERS
    • Testing Age
    • Curing Condition
    • Acid Type
    • Acid Concentration
    • Acid Exposure
    • Exposure Duration
  4. PREDICT

    Click "PREDICT STRENGTH & DURABILITY".

  5. VIEW RESULTS
    • Compressive Strength
    • Split Tensile Strength
    • Flexural Strength
    • Water Absorption
    • Sorptivity
    • Acid Strength Loss/Retention
NOTE:
  • Enter values only within the specified ranges.
  • Predictions are ML-based estimates and should be verified through laboratory testing.
